# Group Eats

Find a place to eat together: search anywhere, vote live, and decide as a group.

- **iPhone or any phone:** open https://evermaat.github.io/group-eats/ in your browser, then add it to your Home Screen.
- **Android app:** [download the latest APK](https://github.com/evermaat/group-eats/releases/latest/download/Group-Eats.apk). Open it to install, and allow installs from your browser if asked.

The Android app adds background notifications and live Google and Yelp scores for the whole table.
